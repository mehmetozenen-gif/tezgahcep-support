Uygulama içi kılavuz

Fotoğraf, ölçü, PDF ve yedek için Ayarlar → Yardım ve Kullanım Kılavuzu’nu açın.

Firma logosu PDF’de görünmüyor

Ayarlar’da en fazla 1 MB boyutunda PNG veya JPEG logo seçin. Teklif Detayı’ndan PDF’yi yeniden oluşturun.

Yeni cihaza geçiş

Eski cihazda Ayarlar → Yedekleme’den JSON dosyası kaydedin. Yeni cihazda dosyayı seçip önizlemedeki kayıt sayısını doğrulayın. Geri yükleme mevcut kayıtları dosyadaki kayıtlarla değiştirir.

TezgahCep support

Mehmet Özenen

In-app guide

Open Ayarlar → Yardım ve Kullanım Kılavuzu (Settings → Help and User Guide) for help with photos, measurements, PDFs and backups.

Company logo missing from the PDF

Select a PNG or JPEG logo of up to 1 MB in Settings. Open Quote Details and create the PDF again.

Moving to a new device

Save a JSON backup from Settings → Backup on the old device. On the new device, select the file and review the record counts before confirming. Restore replaces the current local records with those in the backup.

Report an issue

Email tezgahdestek@ustaturkiye.net with the app version, phone model, operating system version and steps to reproduce the issue. Leave out customer names, phone numbers, real quotes and backups.
